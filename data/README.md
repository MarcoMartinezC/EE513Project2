# Data

Raw files are not committed (size, and the repository is public). This file
says where everything goes and how it was captured. Keep it current: it is part
of the reproduction instructions.

```
data/
  calib/dark/        Project 1 dark frames (lens cap on)
  calib/flat/        Project 1 flat-field frames
  burst/iso100/      capture 1: >= 16 frames per ISO, static scene, tripod
  burst/iso800/
  burst/iso3200/     (one ISO high enough to be visibly noisy)
  detail/            capture 2: one base-ISO frame with fine, high-contrast, saturated detail
  detector/          capture 3: scene01.NEF + scene01.JPG, ... (10-20 scenes)
  pool/              base-ISO frames of OTHER scenes, for the learned denoiser's clean images
  derived/           generated by the scripts (calib.npz, burst_iso*.npz, clean_pool.npz)
  synthetic/         generated by `make demo`
```

Folder names under `burst/` must contain the ISO (`iso3200`); the scripts parse it.

## Capture checklist

Burst (capture 1), per ISO:

- [ ] Tripod, remote release or self-timer, live view or mirror-up (no mirror
      slap), and electronic front-curtain shutter if the body has it. The aim is
      shifts so small that no frame needs resampling (see below).
- [ ] Manual exposure, manual focus, fixed white balance, image stabilisation OFF on a tripod.
- [ ] Same focal length and aperture as the Project 1 flat field (or reshoot the
      flat): lens shading changes with both.
- [ ] Nothing moves: no leaves, screens, people, flickering lights (mains-powered
      LEDs flicker at 100/120 Hz and change exposure frame to frame).
- [ ] Real detail and a range of brightness, so the noise fit sees many signal levels.
- [ ] Exposure the same for every ISO (shorter shutter as ISO rises), so the
      high-ISO burst has fewer photons, which is the point.

Detail scene (capture 2): base ISO, well exposed, fine structure plus at
least one strongly saturated colour (brick, text, fabric, foliage against sky).

Detector scenes (capture 3): RAW + JPEG (Fine) from one shutter press; check
the camera does this before shooting all of them. Include dim, backlit and
high-ISO scenes. Record the in-camera settings that shape the JPEG (Picture
Control, Active D-Lighting, high-ISO NR, lens corrections): they are the
"phone pipeline" you are comparing against.

## Why tiny shifts matter

Every frame that has to be shifted by a fraction of a pixel gets interpolated,
and interpolation averages noise (resampled frames are quieter than real ones)
and blurs fine detail, especially detail near the Nyquist limit of a single
Bayer plane. The scripts never resample the frame used as the noisy input,
but the reference is built from resampled frames. Run
`scripts/build_reference.py` with and without `--no-align` and compare.
